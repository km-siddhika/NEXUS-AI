## 🌟 About the Project

**NEXUS AI** is an AI-powered innovation and project-building platform designed to help students, developers, innovators, and hackathon teams transform real-world problems into meaningful solutions.

Instead of struggling with scattered ideas and unstructured planning, NEXUS AI provides a unified workspace to discover problems, understand their root causes, generate innovative solutions, organize development tasks, collaborate with teams, and prepare professional project presentations.

Our mission is simple:

**Turn ideas into impact.**

## 🎯 Key Features

- **Problem Discovery:** Explore and identify real-world problems worth solving.
- **AI-Powered Analysis:** Break down problems and understand their root causes.
- **Solution Generation:** Generate and explore innovative solution approaches.
- **Project Workspace:** Organize ideas, problem briefs, stakeholders, and project roadmaps.
- **Task Management:** Structure project development into manageable tasks.
- **Collaboration:** Support team-based project planning and coordination.
- **Pitch Builder:** Structure project ideas into compelling presentations.
- **Analytics & Reports:** Track project progress and organize project insights.
- **Modern Dashboard:** Access project tools through a unified interface.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd nexus-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the root directory.

Add the credentials required by the integrations you have enabled.

```env
VITE_GEMINI_API_KEY=your_api_key
```

Never commit API keys, passwords, or private credentials to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
